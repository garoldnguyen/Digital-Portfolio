Ephemeral Polymorphic Defense

A Preliminary Study of Small Language Model Agents for Cloud Security Automation

Quan Nguyen (co-first author), Thach Ngo (co-first author), et al.
Accepted for publication, Springer CCIS (ICONIP 2026)
Cloud Security and Autonomous SLM Systems

The paper proposes a lightweight, stateless Small Language Model architecture built into Cloud-Native Application Protection Platforms to automate real-time security remediation. Randomized persona injection helps resist adversarial prompt injection, and post-task memory teardown leaves no persistent state behind.

1

Demand-driven ingestion

Remediation triggers instantiate stateless SLM agents on demand inside micro-isolated runtimes.

2

Randomized persona injection

Runtime prompt polymorphism neutralizes adversarial injection and jailbreak payloads.

3

Post-task ephemeral teardown

Context and memory are erased after execution, removing persistent state and balancing attack success against task success.
